# Security Policy

## Supported Versions

ffmpegfyMe has no published releases yet. Security fixes land on the default
branch and are released with the next tagged version.

## Reporting a Vulnerability

Report security vulnerabilities privately through GitHub Private Vulnerability Reporting:

[https://github.com/fnayou/ffmpegfyMe/security/advisories/new](https://github.com/fnayou/ffmpegfyMe/security/advisories/new)

Use the **Report a vulnerability** button in the repository **Security** tab.

Until further notice, the maintainer also accepts private reports by email as a
temporary backup:

- fnayou.aymen@gmail.com

Please include:

- Affected component (CLI, Docker image, documentation)
- Vulnerability description and impact
- Steps to reproduce or proof of concept
- Any mitigations or workarounds

Do not open public GitHub issues, discussions, or pull requests for security
reports.

All reports are reviewed and investigated promptly and fairly.
