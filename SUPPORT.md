# Support

Thanks for your interest in ffmpegfyMe.

## Getting help

- Check the [README](README.md) usage instructions first.
- For usage questions, bugs, and feature ideas, open a GitHub issue:
  - Bug reports: use the bug report issue template at
    `.github/ISSUE_TEMPLATE/bug.yml`.
  - Feature requests: use the feature request issue template at
    `.github/ISSUE_TEMPLATE/feature.yml`.

## Security

Do not open public issues for security vulnerabilities. Follow the private
reporting process in [SECURITY.md](SECURITY.md).
